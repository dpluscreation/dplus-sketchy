# D'plus Sketchy

A sketch app for designing ambigrams and mandalas, running entirely in your browser. No account, no server: everything you draw stays on your own computer.

**Try it online:** https://YOUR-USERNAME.github.io/dplus-sketchy/

## Features
- Layers with move / rotate / scale, opacity, blend modes, masks, groups and merge
- Live symmetry preview: Flip H, Flip V, Rotate 180° and a 2-24 segment mandala mode
- Photoshop-style brush engine with pen pressure, custom brushes and a brush-size cursor
- Shift for straight lines, Alt+click colour picker, grid and guides, invert, dark mode
- Canvas size presets (mobile, wallpaper, 4K square and more)
- Preview window with step replay and video export
- Save and open projects (with layers), export PNG
- Installable as an app (PWA) and works offline

## Run it locally
Open `index.html` in Chrome, Edge or Firefox. For the install/offline features, serve the folder over http, for example `python3 -m http.server`, then open http://localhost:8000.

## Keyboard shortcuts
B brush, E eraser, V move, 1/2/3 mirrors, K mandala, G grid, Shift+G guides, I invert, D dark mode, N new layer, Ctrl+J duplicate, Del delete layer, [ ] size, { } hardness, 0 fit, Space pan, P preview, Tab hide panels, Ctrl+Z / Ctrl+Y undo / redo, Ctrl+S save project.
